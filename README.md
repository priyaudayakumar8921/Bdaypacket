# 🎂 ADRU TURNS 22

An interactive birthday countdown adventure website built with **HTML, CSS, JavaScript, Tailwind CSS, GSAP, and Lenis**. Players unlock magical portals through mini-games, puzzles, and challenges as the countdown approaches the special day.

## ✨ Features

* 🌌 Immersive fantasy-themed landing page
* 🎢 Smooth scrolling using Lenis
* 🎭 GSAP-powered animations and transitions
* 🗺️ Interactive unlockable magic path
* ⏳ Real-time countdown timers
* 🎮 Multiple mini-games:

  * Candy Crush Style Match Game
  * Memory Match Challenge
  * Cipher Decoding Puzzles
  * Tic-Tac-Toe Battle
* 🔑 Key collection and portal unlocking system
* 🎁 Daily surprise rewards
* 💌 Personalized messages
* 🎊 Confetti celebrations
* 📱 Fully responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Tailwind CSS
* GSAP
* ScrollTrigger
* Lenis Smooth Scroll
* Canvas Confetti

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/yourusername/adru-turns-22.git
```

2. Open the project folder

```bash
cd adru-turns-22
```

3. Launch `index.html` in your browser.

## 🎯 Gameplay Flow

1. Enter the magical world.
2. Follow the Magic Path.
3. Complete challenges to earn keys.
4. Unlock portals and reveal surprises.
5. Reach the final birthday celebration.
